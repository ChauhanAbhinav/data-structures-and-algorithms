# data-structures-and-algorithms
DSA concepts and problems

## What is DSA?
Data Structures (DS): Ways of organizing and storing data efficiently so that it can be used effectively.
Algorithms (A): Step-by-step procedures or formulas for solving problems using the data.

Think of data structures as “containers” and algorithms as “recipes” to process data inside those containers.

## Why DSA is Important
Efficient code (speed & memory)
Scales to handle millions of users or data points
Helps in competitive programming and interviews
Crucial for system design, AI, backend, and even frontend optimization

## Fundamental Data Structures
### Linear Data Structures
These store data sequentially
Array, linked list, stack, queue

### Non-Linear Data Structures
These store data in a hierarchy or network
Tree and Graph
